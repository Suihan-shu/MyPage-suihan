# 个人主页与内容管理网站

一个基于 Jekyll 和 GitHub Pages 的中文静态网站，集内容展示、旅行日志、电影手记和可视化管理于一体。公开页面以静态文件呈现，后台通过 GitHub API 更新仓库内容，保存后沿用自动构建与部署流程。

## 网站板块

| 板块 | 入口 | 功能 |
| --- | --- | --- |
| 首页 | `/` | 展示简介与站点入口，支持正文和头像更新 |
| 简历 | `/cv/` | 分组展示结构化内容，可在后台通过表单维护 |
| 代码库 | `/repositories/` | 展示精选仓库与项目卡片 |
| 旅行日志 | `/travel/` | 按时间展示文字、照片和地点，支持访问口令与图片预览 |
| 电影手记 | `/movies/` | 展示海报、电影资料、观影日期、个人评分和短评 |
| 管理后台 | `/admin/` | 集中维护简历、首页、旅行、电影及站点文件 |

## 页面体验

- **响应式布局**：适配桌面和手机，提供移动导航与长页面目录。
- **主题切换**：支持明亮、深色及跟随系统的显示模式。
- **站内搜索**：快速查找页面与内容入口。
- **图片浏览**：旅行照片支持缩略图、懒加载和原图预览。
- **电影筛选**：按片名、类型、标签查找记录，并按日期或评分排序。

## 内容管理

管理后台使用 GitHub Personal Access Token 连接仓库。通过表单编辑内容、上传图片并保存后，变更会形成 GitHub 提交；部署状态可在后台查看。

**旅行管理**支持文字或照片动态、实时预览、照片排序与移除，以及已有记录的编辑和删除。

**电影管理**支持 TMDB 搜索选片、按 ID 获取资料、手动添加、卡片预览、个人记录编辑、海报更换、删除和历史版本恢复。TMDB 使用独立的 API 读访问令牌，可在后台输入或从本机配置导入；令牌不会写入电影数据或提交到仓库。本机电影工具也可以单独运行。

内容也可直接在仓库中维护，主要文件如下：

| 文件或目录 | 用途 |
| --- | --- |
| `_config.yml` | 站点配置 |
| `_pages/` | 页面内容与入口 |
| `_data/cv.yml` | 简历数据 |
| `_data/repositories.yml` | 仓库展示配置 |
| `_data/travel.yml` | 旅行记录与访问口令配置 |
| `_data/movies.json` | 电影资料和观影记录 |
| `_layouts/`、`_includes/` | 布局与共享组件 |
| `assets/` | 图片、样式与浏览器脚本 |

## 技术与部署

网站基于 al-folio 主题定制，使用 Jekyll、Liquid、HTML、SCSS 和 JavaScript；内容通过 YAML、JSON 与 Markdown 组织，无需另建云端数据库。

推送到 `main` 分支后，GitHub Actions 会执行结构检查、逻辑测试、静态构建和 GitHub Pages 部署。实际上线时间以工作流完成状态为准。

## 本地预览

安装并启动 Docker 后，在项目目录执行：

```bash
docker compose up
```

预览服务使用 `8040` 端口，页面地址需附加 `_config.yml` 中配置的 `baseurl`。

本机电影管理工具使用 Node.js 24，可在安装项目依赖后启动：

```bash
npm install
npm run movies
```

具体配置与操作见 [电影管理使用说明](tools/movie-manager/README.md)，项目维护约定见 [维护手册](docs/MAINTENANCE_RUNBOOK.md)。
