# Ubuntu双系统安装总结

## 安装前的准备

### 关闭BitLocker

BitLocker是Windows系统对磁盘的保护机制，有的时候电脑出厂内置，如果开启了BitLocker此电脑磁盘界面会有显示一把锁，在windows安全中心或者控制面板里可以关闭。

BitLocker这个选项如果经常折腾电脑的话，一定要将其关闭，要不然电脑死机重装系统或者将固态取出放到别的电脑上备份时会非常麻烦，对磁盘的所有操作都会需要密钥，以防信息的泄漏。除非最后需要处理电脑时可以打开。

### 关闭secure boot

这个最初设计的目的也是为了防止恶意软件安装，防止损伤系统组件，保护系统，但同时这个机制的存在导致无法正常重装系统或者安装双系统，尤其是Winodows系统之外的系统。这个机制需要在BIOS界面里关闭（拯救者进入BOIS系统的方式为：开机快速按F2键），在BIOS系统里的Security选项卡里

### 准备空闲分区

在Windows的磁盘管理界面，进行压缩卷操作，为Ubuntu系统留有至少200G的可用空间，如果存储空间足够大可以留有更大的空间，以防后期空间不够用。如果是双硬盘的话，还需要在C盘留有至少500MB的空闲分区，以保存Ubuntu的系统引导项，只有在系统盘保存它的系统分区在启动时才会有选择系统的界面，否则次次都需要进入BIOS系统来进行系统的切换

### 准备Ubuntu系统镜像

可以在[官网](https://ubuntu.com/desktop)进行下载iso文件，也可以在清华大学等[国内镜像网站进行下载](https://launchpad.net/ubuntu/+cdmirrors)（国内下载访问速度要更快）

在下载前要想清楚安装Ubuntu系统的用途，确定可能会安装哪些软件，然后在网上检索相关的支持性，以确定所安装系统的版本。比如如果需要安装ROS（不是ROS2），那么Ubuntu的最高版本只能是20.04，不能是最新版本，否则安装的软件无法适配。

### 制作系统安装U盘

制作系统安装U盘推荐使用[Rufus](https://rufus.ie/zh/)，不仅是对于Ubuntu系统，其他系统的系统盘也可以使用它，界面简洁，功能强大。制作系统U盘前要将U盘内容进行备份，安装U盘制作过程中会将U盘格式化。

在Rufus中分区类型选择GPT，文件系统选择NTFS

## 双系统安装

### 改变启动项顺序

将U盘插上，进入BIOS界面，需要将U盘设置为第一启动项，以进入Ubuntu安装界面

### 设置语言

根据需求设置，默认为English，在下方可以改为简体中文。虽然选定语言后在系统中可以再添加语言，但是，还是以最初的为主。比如开始选择了英文，后面在系统中进行更改为中文，会发现部分还是保留英文，汉化不完全。首次安装接触Linux系统的花，我推荐中文，在使用过程中遇到一些问题也方便处理。如果对Linux系统比较熟悉或者英语比较OK的话，我推荐英文，毕竟英文才是Linux的初始语言，中文经常有些小bug，比如在tty3界面中文就会出现一些乱码。

### 更新和其他软件

不熟悉的话选择正常安装，不过会多出许多无用的应用比如一些小游戏等，熟悉的话直接最小安装，后面需要啥自己装就行。

其他选项里，推荐都不要勾选。安装Ubuntu时下载更新因为下载源在国外会下载很慢，也就会在安装页面等待很久，可以安装完系统后，直接换源后更新。安装双系统的话，为图形或无线硬件安装第三方软件会安装不知名版本的Nvidia驱动，可能不是你所需的，还要卸载，否则对后续安装会造成影响。但是如果在虚拟机里安装的话就可以直接勾上。

### 安装类型

接下来是三种安装类型的选择

第一种是共存，似乎也是双系统但可能有很多bug

第二种是清空硬盘安装，也就适用于为一台设备安装纯Ubuntu的情形

第三种是大部分人选择的双系统安装方案，不过稍微麻烦点，需要自己对盘进行配置，网上很多配置教程可以网上找一找，可以参照这两篇博客：

### 系统分区

首先对EFI分区进行设置，找到先前在C盘中设置的空闲空间，千万不要搞错，否则会导致Windows系统中文件的丢失甚至系统的损坏。一般C盘的为nvme0，找到其中大小匹配的分区。双硬盘要在C盘单独设置，如果是单硬盘的话可以不手动设置，安装过程中会自动设置

- EFI分区设置为逻辑分区，用于EFI系统，大小500MB左右
- 设置交换空间，在安装Ubuntu的那个盘，逻辑分区，用作交换空间，swap用作虚拟内存，根据自身的物理内存决定
- 设置挂载点/，主要用来存放ubuntu系统文件，相当于C盘。逻辑分区，用于Ext4日志文件系统，大小为50G，挂载点设置为/
- 设置挂载点/home，剩余空间均设置为/home，逻辑分区，用于Ext4日志文件系统。
- /usr挂载点视情况设定，空间不够可不设定

最后安装启动引导器选择之前设置的EFI分区，不要设置错

### 安装

后续按照操作进行安装就行，设置用户名最好别出现中文，出现中文往往在某些地方会出问题，Windows也是。

安装完毕后会提示重启，重启在开机logo界面按提示拔出U盘，按下回车重启

## Ubuntu系统的删除

在安装和配置Ubuntu系统的过程中可能会遇到诸多的问题，删除并重装系统，以下简单介绍完整删除Ubuntu系统的方法

首先把系统启动项更改为Windows，在Windows磁盘管理里将所设置的Ubuntu分区删除。然后在Windows的EFI系统分区删除Ubuntu系统引导项。具体方式参见博客[双系统卸载教程](https://blog.csdn.net/qq_42257666/article/details/120721561?ops_request_misc=%257B%2522request%255Fid%2522%253A%2522170781429516800227453297%2522%252C%2522scm%2522%253A%252220140713.130102334..%2522%257D&request_id=170781429516800227453297&biz_id=0&utm_medium=distribute.pc_search_result.none-task-blog-2~all~sobaiduend~default-1-120721561-null-null.142^v99^pc_search_result_base1&utm_term=%E5%8F%8C%E7%B3%BB%E7%BB%9F%E5%BD%BB%E5%BA%95%E5%88%A0%E9%99%A4ubuntu&spm=1018.2226.3001.4187)的后半部分，前半部分无用，不需要额外下载软件，只需要在磁盘管理中操作即可。操作大致如下：使用diskpart对EFI分区进行分盘设置，使其能显示在此电脑中，然后使用管理员方式打开记事本，在其中打开该盘，找到EFI文件夹，删除其中的Ubuntu

```python
#win+R输入cmd打开命令行
diskpart
list disk
#弹出界面允许
#选择系统盘
select disk 0
list partition
#选择windows的EFI分区，一般200多M
select partition 1
#设定盘符，不要冲突
assign letter=J
#直接管理员运行记事本，按上述步骤操作
#完成后移除盘符
remove letter=J
#完成上述操作后选中Ubuntu系统引导项所在分区，比如为分区5
select partition 5
delete partition override
```
