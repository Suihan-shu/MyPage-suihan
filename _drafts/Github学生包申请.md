# Github学生包申请

## 写在前面

如今AI飞速发展，Agent概念火热，但是身为学生的我们，想要自己使用Agent往往会因为昂贵的Token或订阅价格而却步，这也让我们大部分人很难及时体验到前沿的技术，只是停留在网页端的对话。经常使用IDE的可能会注意到在诸多IDE如VScode中，都会有一个插件叫Github Copilot，最开始也多是ask的形式，随着Agent的发展也逐步推出了agent模式，可以自动帮你编辑代码、新建文件、运行代码等。但我觉得不是说有了这个就可以抛弃基础知识的学习，正如前面Blog所说的，架构越来越重要，要是真的什么都不懂，我觉得是很难用好AI这个工具去实现自己的需求的。我推荐Agent的原因也是觉得我们首先要将工具用起来，然后才会越用越好，如今发展速度越来越快，而且都是在前面的基础上去优化，Agent都用不好，就更别说OpenClaw和Harness Engineering了。就拿我自己而言，其实对Prompt工程很早就有所耳闻，只是一直没放在心上，我个人觉得在网页端就天然不太适合一些Prompt工程，这里面往往会涉及到不同文件的规范，比如有约束行为的文件，有定义流程的文件等等，再加上大部分人网页对话存在一定的不连续性，包括时间的不连续，最开始可能还会注意提示词的书写，到后面就开始随意了，这让prompt工程更难生效了。所以我之前在网页对话端采用给予角色，条件约束，实现目标的简单prompt，而且往往只是在一段对话的开始，后面就根据问题随意发挥了。但后面开始做一些小项目，发现这种形式就容易变得很乱，Agent加上Prompt工程才是正解，通过使用Agent我觉得可以去提高Prompt的能力，它也可以是一个系统，进而更好的使用AI实现需求。包括像ChatGPT也开始大力转型，推出codex，有桌面端也有插件。这些都会有免费额度，但是呢，还是老问题，额度太少了，Agent这种模式需要经常读写文件，本就会消耗大量Token，免费的那些额度根本经不起几次问答。

但是好在Github很早之前就有提供学生包，我最开始认证多是通过它来获得JetBrain全家桶，后面逐步开始用copilot的ask模式，再到现在用Agent。申请学生包只要通过学生邮箱，上传一些有效证明即可获得copilot pro，尽管三月份经历一次大削，把一些最前沿的模型给ban了，得另外付费或者接入相关api，但我觉得还是很良心的。此外由于各种原因，学生包的审核机制越来越严格，很多人会卡在审核阶段，上传材料经常被拒（以前只是需要上传校园卡、学生证就可以通过，现在得学信网认证翻译、还会卡ip等），之前有学弟学妹咨询过相关问题，但是我看网上的解决方案或多或少有一些麻烦的地方，比如说卡IP没提及，翻译学信网认证过于繁琐，遂生出想自己写一篇申请流程的Blog，免得去重复给学弟学妹说这些流程，也可以帮助一些需要的人

## 认证流程

### 认证网站

### 认证注意事项

1. 要添加学生邮箱（以@edu为后缀的）
2. 下载学信网认证（需要翻译成英文，详细操作见后文）
3. IP和定位需要在校内（不要挂梯子）
4. 添加付款方式地址信息（增加通过概率）

### 注册Github账号

首先注册一个GitHub账号，链接为https://github.com/join，可以使用自己的常用邮箱，具体注册流程不多展开

#### Github添加学生邮箱及补充信息

之后进入个人设置-Access-Email，在这里面添加学生邮箱[Account settings](https://github.com/settings/admin)，并注意查收邮箱验证邮件进行验证（如果是直接用教育邮箱注册的GitHub，则可以pass这一步，但不推荐用学生邮箱注册，因为很多学校毕业后会回收邮箱，不便于后续深度使用GitHub）

![image-20260506004850554](./assets/image-20260506004850554.png)

接下来为了提高申请通过率，可以添加一下账单信息[github.com/settings/billing/payment_information](https://github.com/settings/billing/payment_information)（其实只是学校地址罢了），名字用拼音（前面是名后面是姓），最好和验证报告翻译后的保持一致，地址信息这些在学校官网找就行（对应自己所在的校区，一般在官网底部会有），VAT不需要填，所以其实压根没有支付信息

填写完成后，点击【Save billing information】保存账单信息

![image-20260506005251967](./assets/image-20260506005251967.png)

以下是申请被拒给出的一些原因，其中就包含账单信息，所以如果被拒可以检查一下是不是这个信息有缺，还有会是IP和定位问题，会检查IP和定位是不是在学校内，有多个校区的话也需要注意一下

![image-20260506005742237](./assets/image-20260506005742237.png)

### 学信网在线认证申请与翻译

首先就是在学信网的[学信档案](https://my.chsi.com.cn/archive/bab/index.action)里申请在线验证报告，这里是申请中文的在线报告，想要学信网的英文版本需要30元的翻译服务费，申请GitHub学生包大可不必那么规范。

![image-20260506003549841](./assets/image-20260506003549841.png)

申请完成后在右上角可以点击下载保存在线验证报告pdf

![image-20260506004041705](./assets/image-20260506004041705.png)

这里会需要对PDF进行翻译，中文翻译成英文，Github会更容易接受中文的输入，然而直接通过学信网出具英文报告又会比较复杂，因此就直接将中文在线报告翻译即可。报告一般是PDF格式，这里强烈安利一款在线PDF编辑网站，[iLovePDF | 为PDF爱好者提供的PDF文件在线处理工具](https://www.ilovepdf.com)，这是我认为最好用的PDF网站，而且功能都是免费的，界面也很简洁，审美在线（最好用的本地PDF阅读器则是Adobe Acrobat DC，iLove系列除了有处理PDF的网站，还有[iLoveIMG | 图像文件在线编辑工具](https://www.iloveimg.com/zh-cn)，也提供了一些基本图像处理功能）

![image-20260420201835599](./assets/image-20260420201835599.png)

直接打开这个网站，翻到最下方，就有一个PDF翻译，将我们的PDF上传后即可翻译，如果中文界面无法选择英语就切换程英文界面，翻译要注意确保英文版报告完整、清晰，重点包含姓名、学校、就读状态、有效期等信息

![image-20260503152708619](./assets/image-20260503152708619.png)



### 申请学生包

完成以上步骤就可以开始申请了，申请网站：https://github.com/settings/education/benefits

在这个界面点击【Start an application】

![image-20260506012353076](./assets/image-20260506012353076.png)

- 选择身份【Student】（学生）；
- 第二步：选择学校【Select this school】（找到自己的学校，若搜索不到，可核对学校名称拼写）；
- 第三步：点击【Share Location】（分享位置，如果浏览器弹出位置请求则点击允许），再点击【Continue】（继续）；

- 在【Proof】（证明材料）选项中，选择第一个选项【Dated school ID】然后上传翻译后的在线报告；

这个申请审核速度是比较快的，被拒也很快，如果被拒就根据反馈的注意事项重新检查，一般学信网的验证报告是可以一遍过的，校园卡这种貌似已经很难通过了。但是相关权益要1-3天才会发放

在这个界面会显示[GitHub Student Developer Pack - GitHub Education](https://education.github.com/pack)下图

![屏幕截图 2026-04-10 125238](./assets/屏幕截图 2026-04-10 125238.png)

通过之后到时候会收到一封邮件

![image-20260506020329456](./assets/image-20260506020329456.png)

之后就能有用以下这些权益了，最有用的是GitHub Copilot pro、JetBrains(Pycharm、IDEA等)全家桶还有1Password，当然不仅限这些还有一些免费服务器和课程等等，大家可以自行探索

![image-20260506020701502](./assets/image-20260506020701502.png)

### 申请Copilot

现在Copilot的权益不会自动到账，需要主动领取，[GitHub Student Developer Pack - GitHub Education](https://education.github.com/pack)在该界面找到申请即可

![屏幕截图 2026-04-13 115407](./assets/屏幕截图 2026-04-13 115407.png)



![屏幕截图 2026-04-13 115647](./assets/屏幕截图 2026-04-13 115647.png)

申请完成后由于Copilot条款的变更，你所有的数据默认会被拿去训练，但是可以手动选择关闭

在[Copilot](https://github.com/settings/copilot/features)滑到最底部，在隐私设置里把Privacy第二个选项关了即可

![image-20260506021819378](./assets/image-20260506021819378.png)

基本流程就这些，希望大家申请顺利，开启Agent之路

## 2026.05.06二编

没想到这篇Blog发出不久后，Copilot发生两次重大改变，**从 2026 年 4 月 20 日起**，新的注册Copilot Pro、Copilot Pro+和学生计划将暂时暂停。也就是说现在暂时没法获得Copilot Pro权益了，可能是与Copilot计划的变更有关再加上算力资源紧张，它在4.28日Copilot宣布转向按token量计费：6 月 1 日起改用 AI Credits，没想到这天来的这么快。后续应该还是会恢复权益的，所以还是可以先认证一下，看看其他学生包权益能不能用上，且薅且珍惜吧

### 个人感悟

最近其实用copilot体验越来越差了，先是三月份宣布高级模型付费，四月越到后面可用模型越来越少了，而且多了一个五小时限制和周限制，我没有准确统计过这个，但使用差不多专注ai code一两个小时，就会触发五小时限制，周限制也是/就这个限制没解决多少问题很快就达到了，此外经常会出现中断回答的情况，使用体验很差。一旦到了限制就中断回答，这是想继续使用只能切换至auto（根据官方文档），切换过几次，前后效果差异很大，模型性能差别太大了，一些简单的ask还没问题，一旦复杂起来很难达到预期效果，而且后续按token计费很有可能auto也没法用了。

可能也是现在算力资源紧张吧，在四月之前用Copilot确实很顺手，而且每个月都能把额度用满。对于Copilot的行为也能理解吧，感觉以后免费的agent会越来越少了。最近折腾来折腾去，我已经开始尝试新方案了，加上DeepSeek V4的推出，性价比拉满，非常适合学生党，我尝试Claude配置DeepSeek V4来使用Agent，后续可能再有一篇Blog讲如何去配置，最近开始深度使用测试其能力。
