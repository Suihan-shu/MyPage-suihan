欢迎来到我的个人博客！

为了让主页的更新与记录更加随心所欲，今天为主页搭建了一套**基于 GitHub REST API 的纯前端个人专用发布系统**。

### 核心亮点

1. **零服务器成本**：直接在网页前端调用 GitHub 官方 API 进行文件读取与提交。
2. **多端随时发布**：无论是手机、平板还是电脑，随时随地在浏览器中发动态、写文章。
3. **图片一键直传**：支持剪贴板粘贴与拖拽，自动编码提交至仓库对应目录，自动生成 Markdown 引用。
4. **安全可控**：身份凭证（Personal Access Token）仅保存在当前浏览器本地，其他人无法修改任何内容。
